# test

This folder is managed by BL03U MassSpectrumTool.

## Directory Map
- `config/`: 项目级设置（YAML）
- `raw_data/`: 原始谱图、样品信息和导入记录
- `calibration/`: 定标点、定标参数和标定结果
- `spectrum_analysis/`: 寻峰、卡峰范围和高斯拟合产物
- `temperature_scan/`: 温度扫描曲线、表格和图像
- `pie_analysis/`: PIE 曲线、物种拟合和鉴定结果
- `mole_fraction/`: 摩尔分数计算输入、结果和图像
- `final_report/`: 汇总报告、说明文档和发表用图表
- `versions/`: 项目级 zip 快照和备份
