# Treat curves as independent scientific results

A Scientific Analyst-reviewed PIE Curve or Temperature Response Curve is a complete scientific result when accompanied by Project Evidence, even if species interpretation, isotope correction, PICS fitting, or mole-fraction quantification cannot proceed. Downstream analysis may deepen the available evidence but must not retroactively make a valid upstream Curve Result incomplete.

Completion is therefore assessed independently for Curve Results, Interpretation Results, and Quantitative Results. A blocked downstream stage records its reason without changing the approval state of upstream results.
